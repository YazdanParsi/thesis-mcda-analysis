# TOPSIS Cloud Provider Evaluation

Companion code for the bachelor thesis *"The Integration of Artificial Intelligence in Cloud Computing"* (Czech University of Life Sciences Prague, 2025).

Applies the TOPSIS multi-criteria decision analysis method to evaluate AWS, Azure, and GCP for AI inference workloads across five criteria: performance, cost, reliability, security, and scalability.

## Structure

```
src/
  mcda_engine.py            TOPSIS implementation and thesis decision matrix
  sensitivity_analysis.py   Scenario-based and weight-perturbation analysis
data/
  mcda_dataset.csv          Decision matrix (Table 2)
  data_sources.json         Source registry with URLs and access dates
  *.json                    Supporting data (pricing, SLAs, benchmarks, etc.)
results/
  sensitivity_results.json  Generated by sensitivity_analysis.py
```

## Usage

```bash
pip install -r requirements.txt

cd src
python mcda_engine.py              # baseline TOPSIS ranking
python sensitivity_analysis.py     # full sensitivity analysis (16 scenarios)
```
